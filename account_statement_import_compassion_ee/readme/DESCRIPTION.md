This module, **Enterprise Bank Statement Import for Compassion**, enhances the bank statement import functionality from both OCA and Enterprise edition in Odoo for Compassion. It provides the following features:

1. **Attachment of Source Files**: When bank statements are imported, the source files are automatically attached to the statements for easy reference.

2. **Auto Reconciliation**: After importing bank statements, the module attempts to automatically reconcile the statement lines using a background job. This ensures that the reconciliation process is efficient and reduces manual effort.
