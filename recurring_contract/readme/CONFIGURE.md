1. Make sure you have the full accounting features enabled in your account.
   In order to do this, go in Settings/Users& Companies/Groups and search for
   "Show Full Accounting Features". Add your user to the group.
2. Make sure you have products with the Income account property set.
   On a product page, go to the "Accounting" tab and set the "Income account" field.
3. Make sure you have at least one Journal of type Sale in your company.
   The first journal of type Sale will be used to post the income from the recurring contracts.
